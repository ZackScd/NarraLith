# NarraLith

Herramienta de escritorio **offline-first** para escritura narrativa y construcción de mundo (manuscrito + worldbuilding + referencias cruzadas).

## Requisitos

- Node.js 20+
- Rust (stable)
- [Prerrequisitos de Tauri](https://tauri.app/start/prerequisites/) para tu sistema operativo

## Desarrollo local

```bash
npm install
npm run tauri dev
```

Otros scripts: `npm run build`, `npm run lint`, `npm run format`.
